## 决策记录（M7 起补登，完整列表见 docs/status-and-plan.md）

| 编号 | 决策 | 理由 |
|------|------|------|
| D22 | 应用名改回「日迹」（M11 执行） | 用户拍板；影响桌面图标名，不动包名 |
| D23 | 提醒每周天数拆分到 `Reminder.daysOfWeek`（v1→v2 迁移复制旧数据） | 原与频率规则共享 `daysOfWeek`，保存会互相覆盖、污染统计口径 |
| D24 | CUSTOM 频率 = 每隔 N 天（1..90），锚点 = 保存当天；改 N 重置锚点，其他编辑保留；缺参数退化每天 | 语义可确定、可统计、可测试 |
| D25 | 「跳过」统一写 `rule.skipDates`（休息日/请假登记），UI 不再新建 `status=SKIPPED` 记录（旧数据仍参与统计） | 日级语义与统计口径一致；可撤销、不产生记录噪音；未来日期可提前登记；受 allowSkip 门控 |
| D26 | 「部分完成」= 始终追加 `status=PARTIAL` 记录，不参与 MERGE/ACCUMULATE 合并目标（合并只认 DONE） | 部分完成是过程量，合并语义模糊；避免覆盖与状态污染 |
| D27 | 「计划中」仅限未来日期（`date > today`），同日同选项重复计划更新最近一条（upsert） | 与 BackfillPolicy 现有窗口无冲突；防计划重复堆积 |
