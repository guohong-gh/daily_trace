## 决策记录（M7 起补登，完整列表见 docs/status-and-plan.md）

| 编号 | 决策 | 理由 |
|------|------|------|
| D22 | 应用名改回「日迹」（M11 已执行） | 用户拍板；影响桌面图标名与小组件标题，不动包名 |
| D23 | 提醒每周天数拆分到 `Reminder.daysOfWeek`（v1→v2 迁移复制旧数据） | 原与频率规则共享 `daysOfWeek`，保存会互相覆盖、污染统计口径 |
| D24 | CUSTOM 频率 = 每隔 N 天（1..90），锚点 = 保存当天；改 N 重置锚点，其他编辑保留；缺参数退化每天 | 语义可确定、可统计、可测试 |
| D25 | 「跳过」统一写 `rule.skipDates`（休息日/请假登记），UI 不再新建 `status=SKIPPED` 记录（旧数据仍参与统计） | 日级语义与统计口径一致；可撤销、不产生记录噪音；未来日期可提前登记；受 allowSkip 门控 |
| D26 | 「部分完成」= 始终追加 `status=PARTIAL` 记录，不参与 MERGE/ACCUMULATE 合并目标（合并只认 DONE） | 部分完成是过程量，合并语义模糊；避免覆盖与状态污染 |
| D27 | 「计划中」仅限未来日期（`date > today`），同日同选项重复计划更新最近一条（upsert） | 与 BackfillPolicy 现有窗口无冲突；防计划重复堆积 |
| D28 | 统计总量 = 全时段累计（不随范围切换）；次数只算 DONE（PARTIAL 单独计数）；量值合计含 DONE+PARTIAL（与今日页一致）；PLANNED/SKIPPED 不计；计数型「总次数」取数值合计；按 itemId 隔离 | 总量语义与今日页口径统一；`StatsCalculator.totals` 纯函数可穷举（M7-4） |
| D29 | 日历标记 = 逐选项快照色圆点：DONE/PARTIAL 产点、同项同日合一（色取当天最新一条）、按选项管理顺序、最多 4 个 +「+N」；PLANNED/SKIPPED 不产点、跳过日不单独标记；备注保留第三色点 | 与 D11 快照展示、D25 跳过语义一致；覆盖验收 5/6（M7-5） |
| D30 | 长按日期 = 当日摘要对话框（快照名/值/状态 + 休息日名单 + 日期备注 + 「查看详情」）；无内容的空日不弹（长按等同点击） | 不新增页面层级；摘要与筛选联动一致（M7-5） |
| D31 | 日历联动今日页「已应用筛选」仅取选项/分组范围（`FilterMatcher.itemMatches`），忽略 dayFilter；沿用 savedStateHandle 机制（D12）；日历页显示「筛选：xxx」指示条、清除仍只在今日页 | 避免「未打卡」辅助筛清空日历；一处应用全局可见（M7-5） |
| D32 | 日历翻月 = 1970-01 ~ 2100-12 固定虚拟页（1572 页），边界停住不回绕；记录/备注窗口 = 当前月 ±1（相邻页预取）；年月选择器 = 年步进 + 3×4 月网格、点月即跳转；远距（>2 页）直接定位 | 翻月范围可控可测；相邻预取保证滑动无空白；标题即入口、不增页面层级（M8-1） |
| D33 | 日历视图 tab = 月 / 周（后续批次追加 年 / 时间线），点击切换、tab 之间不横滑；横滑留给各视图自身翻页（月 = 翻月、周 = 换周、年 = 换年）；筛选指示条与「今天」所有视图共用（「今天」按视图回当前月 / 本周） | 分层交付、每批可独立验收；手势分工避免 tab 横滑与视图翻页冲突（M8-2a） |
| D34 | 周视图 = 行（未删除选项、管理顺序）× 列（周内 7 天）状态网格；格状态优先级 完成 > 部分 > 计划 > 跳过（当天有记录时跳过不覆盖），跳过来自规则 `allowSkip + skipDates`（D25）；实心 / 半透明 / 空心 / 灰杠区分；回收站选项不作为行、归档选项保留 | 与 D11 快照展示、D25 跳过语义、D29 圆点口径一致；表格便于一眼看清一周完成度（M8-2a） |
| D35 | 年热力图 = 竖版 7 列（周起始按设置）× 53/54 行动态行数（年首周 ~ 年尾周，年外格留白）、卡片内竖向滚动；强度 = 当日去重 DONE 选项数分档 0/1/2/3/4+（PARTIAL/PLANNED/SKIPPED 不计，与 D28 一致）；筛选沿用 D31（抽出 `ItemScope` 与 `CalendarMarks` 共用）；‹年› + 横滑换年（1970 ~ 2100，131 页，停住不回绕）、「今天」回当年；数据窗口 = 当年 ±1 年、摘要只算当年；今天格高亮环、打开当年自动滚到今天行；汇总行「完成项次 + 打卡天数」 | 一眼看清全年密度与打卡天数；窗口/翻年范围可控可测；月份栏补足纵向定位（M8-2b） |
| D36 | 时间线 = 倒序日流（只列有内容的天：命中筛选的记录 / 休息日登记 / 日期备注，口径完全复用 D30/D31 摘要），卡片 = 日期 + 今天徽标 + 条数 + 条目 + 休息日 + 备注，点击进日期详情、长按弹 D30 摘要（与月/周/年一致）；默认窗口含今天共 30 天、「加载更早」每次再回溯 30 天（下限 1970-01-01；更早是否有内容由记录/备注存在性查询判定，无则显「已到最早记录」）；「今天」重置回最近 30 天并回到顶部；窗口上界 = 今天（未来计划不在时间线展示） | 日流聚焦有内容的日子、空日不干扰；分页窗口可控、避免无限空载；未来计划已有月/周/年承载（M8-2c） |
| D37 | 批量记录默认值直记：BOOLEAN=完成（已完成跳过）、COUNT=+1、DURATION/VALUE=选项目标值 → 截至日期最近一次记录值，均无则该行置灰不可批量（走现有单笔写入，multiRecordRule 一致）；批量删除记录 / 彻底删除选项均加确认框；批量改备注 =「应用」（非空覆盖）+「清除备注」（清空）；管理页一次只在一个分区内多选（使用中/已停用 → 归档/移入回收站；已归档 → 取消归档/移入回收站；回收站 → 恢复/彻底删除），「停用/启用」不批量化；交互 = 长按进多选 + 顶栏「已选 N / 全选 / 取消」+ 底部操作条 + 返回键先退出 | 直达常用值、少填表；复用单笔写入保证规则一致；分区限定避免跨状态误操作（M8-3） |
